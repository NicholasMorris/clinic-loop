Compliance layer: jurisdiction-keyed rulesets, PII redaction, pseudonymisation, and ingress module.

- `load_ruleset(jurisdiction)` returns a validated ruleset; AU is populated; UK and NZ raise `RulesetNotImplemented`; `None` returns AU with fallback banner.
- `redact(text)` removes nine PII classes (Medicare, TFN, phone, email, DOB, street address, NZ NHI, UK NHS, synthetic-roster names) using pattern matching and checksum validators.
- `pseudonymise(value, run_key)` returns stable keyed-HMAC tokens; `current_run_key()` generates per-process keys never written to disk.
- `ingress.process_record(record)` redacts PII at module boundary; raw identifiers unreachable from public surface.

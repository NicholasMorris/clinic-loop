Implement M0-2: local CI gate, conformance test registry, and pytest-socket policy.

Adds `make ci` target that runs ruff, mypy, pytest, then discovers and executes checks/*.sh. Introduces `tests/conformance/` with a registry that maps requirement identifiers to test node IDs. All tests run with pytest-socket configured for loopback-only connections. Registers five requirement identifiers: B1 (repo settings), D6 (lint/types), L1 (inference loopback), L6 (speech service blocklist), and P4 (fragment check).

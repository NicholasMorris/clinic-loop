Add metrics module for SimClinic: throughput, median wait, SLA breaches, and cost per order.

The module turns a completed `RunResult` into a frozen, versioned `MetricSnapshot` with four metric families:
- **Throughput**: orders completed and orders per simulated hour
- **Median wait**: per-queue median time until service starts
- **SLA breaches**: count per rule ID with inventory citations
- **Cost per order**: busy labor hours × hourly cost / completed orders (idle capacity excluded)

Key features:
- Deterministic computation from event log only
- All metrics have single documented definition and implementation
- Snapshots serialized to `var/snapshots/run-<seed>.json` with schema versioning
- Per-queue SLA wait targets in `sla_targets.toml` (intake 60m, prescriber 240m, pharmacy 480m, support 120m)
- Handles empty runs (zero completed orders) with `cost_per_order=None`

Requirement: C0 (SimClinic)

Implement TriageAgentPort (M2-7) to integrate the triage agent into SimClinic as a replaceable worker for the support inbox queue. The port runs the compiled triage graph for each arriving message, auto-approving the draft if it pauses at the human approval gate (simulation-only behavior), and routing escalations and blocks back to the human queue. Six acceptance criterion tests verify protocol conformance, toggle effect on queue depth, determinism, fallback behavior, outbound port wiring, and per-tick capacity observation. Docs explain the simulation-only auto-approval design and the three exception types (CaseEscalated, DraftNeedsHumanReview, HumanApprovalPending) that trigger fallback routing.

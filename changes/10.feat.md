Implement the HITL (human-in-the-loop) kernel for LangGraph agents, providing durable pause and resume mechanisms for human approval gates and multi-turn question loops. Includes HumanDecision pydantic model with approval/edit/reject actions, per-agent SQLite checkpointing at var/checkpoints/<agent_name>.sqlite, static interrupt_before approval gates with update_state resumption, dynamic interrupt() question loops for multi-turn Q&A, and list_pending() for review console integration. Reference graph demonstrates the pattern with typed state schema and two conditional edges.

TriageState: typed, validated pydantic model carrying case identity, redacted thread with patient text in a delimited field, detected language, classified intent, escalation clear token, tool calls with state-bound arguments, draft text, guard verdicts and human decision. Triage nodes: ingest (redact PII, detect language, build patient_data_block), classify_intent (LLM intent classification with cassette replay), resolve (call tools with state-bound patient_id and order_id, never from model), draft (escalation and language checks, no model call for non-English), regulatory_guard (check draft before human approval), guard_final (re-check post-edit text after human decision). Escalation tokens: HMAC-authenticated EscalationClear dataclass with text_sha256 and mac, per-machine key rotation, gate prevents draft without matching token.

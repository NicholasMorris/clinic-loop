Discrete-event simulation engine for SimClinic: heap-based event loop with four named queues (intake, prescriber_review, pharmacy_fulfilment, support_inbox), worker pool configuration loaded from `staffing.toml` with required assumed labels, SLA rule mappings to inventory IDs (termination_cutoff ps-03, damage_report_window ps-04, dispatch_commitment po-01), deterministic run hash for reproducibility, and jurisdiction-specific regime parameters with error handling for unimplemented NZ/UK regimes.
